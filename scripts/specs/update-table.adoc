=== Purpose

This document specifies the `update-table` script,
which updates the "List of requirements" table
of the link:../asciireq-specification.adoc[AsciiReq specification].

=== Conventions

This document is written with the <<ASCIIREQ>> format.

This document uses <<RFC-2119>> and <<RFC-8174>> conventions
for the understanding of the capitalized keywords
"MAY",
"MUST", "MUST NOT",
"SHALL", "SHALL NOT",
"SHOULD", "SHOULD NOT",
"REQUIRED", "RECOMMENDED", and "OPTIONAL".

== Requirements

=== Functional

[#UPDATE-TABLE-0100, reftext="UPDATE-TABLE-0100", .req]
UPDATE-TABLE-0100:: List of requirements update
+
--
The `update-table` script MUST update
the <<REQUIREMENTS-TABLE>>
of the <<ASCIIREQ>> specification,
so that it gives
the identifiers and titles
of all the requirements
contained in the <<ASCIIREQ>> specification.
--


=== Implementation

[#UPDATE-TABLE-0200, reftext="UPDATE-TABLE-0200", .req]
UPDATE-TABLE-0200:: TypeScript implementation
+
--
The `update-table` script MUST be implemented in TypeScript,
with its source files
placed in the `scripts/src/` subdirectory
of the <<ASCIIREQ>> specification repository.
--


=== Design

The design of the `update-table` script
relies on the <<ASCIIDOCTOR-JS>> library,
in order to parse the AsciiDoc content
in a robust way,
instead of relying on fragile text processing.

[#UPDATE-TABLE-0300, reftext="UPDATE-TABLE-0300", .req]
UPDATE-TABLE-0300:: Asciidoctor.js based design
+
--
The `update-table` script MUST use
the <<ASCIIDOCTOR-JS>> library
to parse the <<ASCIIDOC>> content
of the <<ASCIIREQ>> specification,
and to generate the updated <<REQUIREMENTS-TABLE>>.

The built script MUST be placed
in the `scripts/dist/` subdirectory
of the <<ASCIIREQ>> specification repository.
--
