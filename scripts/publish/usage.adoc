= Usage of the `asciireq-publish` tool

`scripts/publish/` is a self-contained npm package holding the publish tool:
`asciireq-publish.js`, `package.json` and `package-lock.json`.

The AsciiReq specification sources live in `src/`, split into one `.adoc` file per
section, included from `src/asciireq-specification.adoc` with
`include::...[leveloffset=+1]` directives.
GitHub does not resolve AsciiDoc `include::` directives when rendering `.adoc`
files, so the tool publishes self-contained copies at the repository root
(`README.adoc` and `asciireq-specification.adoc`) with all includes resolved.

The version of the specification is read from the `VERSION` file at the
repository root, and the publication date is the current date: `npm run publish`
resolves in place each `:revnumber:` / `:revdate:` placeholder line declared
in the header of a published source (e.g. `:revnumber: (resolved from the
VERSION file when published)`) — `:revnumber:` from the `VERSION` file,
`:revdate:` from the current date — when publishing at the repository root.
Each placeholder is resolved independently: `src/README.adoc` declares only
`:revnumber:`, so the published `README.adoc` gets the version but no date.
Bump the `VERSION` file when releasing a new version.

Usage:

[source,sh]
----
cd scripts/publish
npm clean-install
npm run publish
----
