[#data]
== Data

The following data definitions help writing this specification
in a more formal way.


[#data-document]
=== AsciiReq document

[#ASCIIREQ-DOCUMENT, reftext="ASCIIREQ-DOCUMENT", .req-data]
ASCIIREQ-DOCUMENT:: _AsciiReq document_
+
--
<<ASCIIDOC>> document following the <<ASCIIREQ>> specification.

May be defined with different `.adoc` files
using the <<ASCIIDOC>> ability to include files
(as of <<ASCIIREQ-DOC-0110>>):
the <<ASCIIREQ-DOCUMENT>> is then the main file
with its includes resolved.
--

[#ASCIIREQ-VERSION-DOCUMENT-ATTRIBUTE, reftext="ASCIIREQ-VERSION-DOCUMENT-ATTRIBUTE", .req-data]
ASCIIREQ-VERSION-DOCUMENT-ATTRIBUTE:: _``:asciireq-version:`` document attribute_
+
--
Specific <<ASCIIDOC>> document attribute for <<ASCIIREQ>> (as of <<ASCIIREQ-HEADER-0200>>)
giving the version of <<ASCIIREQ>> specification used,
and stating consequently that the <<ASCIIDOC>> document is actually an <<ASCIIREQ-DOCUMENT>>.
--

[#ASCIIREQ-DOCUMENT-VERSION, reftext="ASCIIREQ-DOCUMENT-VERSION", .req-data]
ASCIIREQ-DOCUMENT-VERSION:: _AsciiReq document version_
+
--
Version of an <<ASCIIREQ-DOCUMENT>>,
as of <<ASCIIREQ-VERSIONING-1100>>.
--


[#data-items]
=== AsciiReq items

[#ASCIIREQ-ITEM, reftext="ASCIIREQ-ITEM", .req-data]
ASCIIREQ-ITEM:: _AsciiReq item_
+
--
General AsciiReq item (as of <<ASCIIREQ-ITEM-0300>>).
--

General <<ASCIIREQ-ITEM>>s
correspond to one of the following specialized items.

[#ASCIIREQ-ACTOR, reftext="ASCIIREQ-ACTOR", .req-data]
ASCIIREQ-ACTOR:: _AsciiReq formal actor_
+
--
<<ASCIIREQ-ITEM>> for a formal actor definition (as of <<ASCIIREQ-ITEM-0300>>).
--

[#ASCIIREQ-DATA, reftext="ASCIIREQ-DATA", .req-data]
ASCIIREQ-DATA:: _AsciiReq formal data_
+
--
<<ASCIIREQ-ITEM>> for a formal data definition (as of <<ASCIIREQ-ITEM-0300>>).
--

[#ASCIIREQ-REQUIREMENT, reftext="ASCIIREQ-REQUIREMENT", .req-data]
ASCIIREQ-REQUIREMENT:: _AsciiReq requirement_
+
--
<<ASCIIREQ-ITEM>> defining a requirement (as of <<ASCIIREQ-ITEM-0300>>).
--

[#ASCIIREQ-REF, reftext="ASCIIREQ-REF", .req-data]
ASCIIREQ-REF:: _AsciiReq foreign reference_
+
--
<<ASCIIREQ-ITEM>> for a foreign reference definition (as of <<ASCIIREQ-ITEM-0300>>).
--


[#data-item-parts]
=== AsciiReq item parts

[#ASCIIREQ-IDENTIFIER, reftext="ASCIIREQ-IDENTIFIER", .req-data]
ASCIIREQ-IDENTIFIER:: _AsciiReq item identifier_
+
--
Identifier (as of <<ASCIIREQ-ID-0400>>)
of an <<ASCIIREQ-ITEM>>.
--

[#ASCIIREQ-COMPOUND-CONTENT, reftext="ASCIIREQ-COMPOUND-CONTENT", .req-data]
ASCIIREQ-COMPOUND-CONTENT:: _AsciiReq item content_
+
--
Compound content (as of <<ASCIIREQ-ITEM-0310>>)
attached with an <<ASCIIREQ-ITEM>>.
--

[#ASCIIREQ-TITLE, reftext="ASCIIREQ-TITLE", .req-data]
ASCIIREQ-TITLE:: _AsciiReq item title_
+
--
Optional title (as of <<ASCIIREQ-TITLE-0500>>)
of an <<ASCIIREQ-ITEM>>,
part of the <<ASCIIREQ-COMPOUND-CONTENT>>.
--

[#ASCIIREQ-BODY, reftext="ASCIIREQ-BODY", .req-data]
ASCIIREQ-BODY:: _AsciiReq item body_
+
--
Body (as of <<ASCIIREQ-BODY-0600>>)
of an <<ASCIIREQ-ITEM>>,
part of the <<ASCIIREQ-COMPOUND-CONTENT>>.
--

[#ASCIIREQ-ATTRIBUTE, reftext="ASCIIREQ-ATTRIBUTE", .req-data]
ASCIIREQ-ATTRIBUTE:: _AsciiReq requirement attribute_
+
--
One attribute
in the attribute set (as of <<ASCIIREQ-ATTRIBUTES-0700>>)
of an <<ASCIIREQ-REQUIREMENT>> (requirements only!),
part of the <<ASCIIREQ-COMPOUND-CONTENT>>.
--


[#data-attributes]
=== Common attributes

[#ASCIIREQ-REQUIREMENT-VERSION, reftext="ASCIIREQ-REQUIREMENT-VERSION", .req-data]
ASCIIREQ-REQUIREMENT-VERSION:: _AsciiReq requirement version_
+

Version of an <<ASCIIREQ-DOCUMENT>>,
as of <<ASCIIREQ-VERSIONING-1120>>.
