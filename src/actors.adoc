[#actors]
== Actors

The following actors interact with AsciiReq specifications.

[#ASCIIREQ-WRITER, reftext="ASCIIREQ-WRITER", .req-actor]
ASCIIREQ-WRITER:: _AsciiReq writer_
+
--
Writes and maintains AsciiReq specifications.

In order to be able to maintain AsciiReq specifications,
ASCIIREQ-WRITERs implicitly also have ASCIIREQ-READER abilities.

May be a human or a tool.
--

[#ASCIIREQ-READER, reftext="ASCIIREQ-READER", .req-actor]
ASCIIREQ-READER:: _AsciiReq reader_
+
--
Reads AsciiReq specifications.

May be a human or a tool.
--

[#ASCIIDOC-RENDERER, reftext="ASCIIDOC-RENDERER", .req-actor]
ASCIIDOC-RENDERER:: _AsciiDoc renderer_
+
--
Reads <<ASCIIDOC>> documents
(possibly containing <<ASCIIREQ>> content)
and makes a visual presentation of it for humans.

Basically a tool.

Examples:

* link:https://asciidoctor.org/[asciidoctor]
* link:https://marketplace.visualstudio.com/items?itemName=asciidoctor.asciidoctor-vscode[AsciiDoc] VSCode extension
* Git platforms, such as link:https://github.com/[GitHub]
* ...
--
