= AsciiReq - Requirements with AsciiDoc

== What it is

This project specifies a format based on AsciiDoc to write requirements.

Requirement Management tools are not part of this repository,
but are then expected as tier tools.


== Example

[source, asciidoc]
----
[.req]
REQ-010::
Requirement title
--
Text defining the requirement body.

The requirement body may contain several paragraphs.

It may also use regular AsciiDoc formatting syntax
(such as lists, tables, admonitions, ...)
--
* Version: 1.0.0
* Type: example
* Refers: UPPER-REQ-100
** Coverage justification.
----

NOTE: Syntax inspired
from the [AsciiReqs](https://github.com/hpenne/asciireqs) project.
