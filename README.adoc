= AsciiReqs2 - Requirements with AsciiDoc

== What it is

This project specifies a format based on AsciiDoc to write requirements.

It is named AsciiReqs2 in as much as it is initially inspired from
the [AsciiReqs](https://github.com/hpenne/asciireqs) project.

Contrary to AsciiReqs, which comes as a tool,
AsciiReqs2 does not implement anything, but just specifies the requirement format.

Requirement Management tools are then expected as tier tools.


== Example

[source, asciidoc]
----
[.req]
REQ-010::
This is the (optional) requirement title
--
This is the text defining the requirement.

The text can span multiple lines.

It may also use regular AsciiDoc formatting syntax
(like lists, tables, admonitions, ...)
--
* Version: 1.0.0
* Type: example
----
