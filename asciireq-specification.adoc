= AsciiReq Specification
:toc:


== Introduction

This document specifies the AsciiReq format,
used to write requirements with AsciiDoc.

An AsciiReq document is a regular AsciiDoc document.
Requirements are written inside it, following the conventions defined below,
so that they can be identified, referenced and processed by tier tools.

The following example shows the format in action:

[source, asciidoc]
----
[.req]
REQ-010::
This is the (optional) requirement title
--
This is the text defining the requirement.

The text can span multiple lines.

It may also use regular AsciiDoc formatting syntax
(like lists, tables, admonitions, ...)
--
* Version: 1.0.0
* Type: example
----


== Requirements

The requirements defining the AsciiReq format are listed below.

NOTE: They are themselves written with the AsciiReq format.


=== Requirement structure

[.req]
REQ-010::
Requirement identifier
--
A requirement has an identifier, unique across the document.

The identifier is written on a single line, preceding the
requirement statement.
--
* Version: 1.0.0
* Type: format

[.req]
REQ-020::
Requirement title
--
A requirement may have a title:
a short phrase summarizing the requirement,
written just after the identifier.
--
* Version: 1.0.0
* Type: format

[.req]
REQ-030::
Requirement body
--
A requirement defines a body:
the text describing what is required.

The statement may span several lines
and may use any AsciiDoc formatting (lists, tables, admonitions, ...).
--
* Version: 1.0.0
* Type: format

[.req]
REQ-004::
Requirement attributes
--
A requirement may carry metadata, written as a AsciiDoc list of
`name: value` pairs, placed after the requirement statement.

Metadata may for instance define the version and the type of the
requirement.
--
* Version: 1.0.0
* Type: format
